# Pruebas

No se recibió una suite de pruebas automatizadas en el proyecto original. Esta carpeta documenta verificaciones manuales sugeridas; registrar fecha, responsable, resultado y evidencia al ejecutarlas.

## Lista de verificación inicial

- [ ] El servidor inicia con configuración local válida.
- [ ] La página de catálogo carga productos desde MySQL.
- [ ] Un cliente puede registrarse con datos de prueba.
- [ ] El inicio de sesión acepta credenciales válidas y rechaza inválidas.
- [ ] Un usuario no autenticado no puede registrar pedidos.
- [ ] El sistema rechaza cantidades inválidas o stock insuficiente.
- [ ] Un pedido válido guarda cabecera y detalles.
- [ ] El stock se descuenta al registrar la compra.
- [ ] El Vendedor puede consultar y actualizar pedidos según permisos.
- [ ] Se verifica el comportamiento de cancelación y restitución de stock (pendiente de evidencia en el informe).
