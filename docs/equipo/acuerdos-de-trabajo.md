# Organización del trabajo individual

Jardín Online se desarrolla de manera individual. Por ello, no se establecen acuerdos entre varios integrantes.

## Criterios de organización

1. Mantener `main` como rama estable del repositorio.
2. Utilizar ramas descriptivas cuando se trabaje en cambios importantes.
3. Usar commits claros, por ejemplo `docs: actualizar requisitos` o `fix: validar stock en pedidos`.
4. Revisar localmente los cambios antes de publicarlos.
5. Registrar tareas, errores y mejoras mediante GitHub Issues.
6. No subir `.env`, contraseñas, tokens, datos personales ni volcados con información real.
7. Actualizar la documentación cuando cambie el comportamiento del sistema.
8. Identificar como pendiente cualquier función diseñada pero aún no implementada.
