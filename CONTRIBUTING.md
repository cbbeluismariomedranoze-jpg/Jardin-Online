# Contribuir a Jardín Online

1. Crea una rama para cada tarea: `feat/nombre`, `fix/nombre` o `docs/nombre`.
2. Realiza cambios pequeños y relacionados con una tarea.
3. Comprueba manualmente las funciones afectadas y registra el resultado.
4. Usa mensajes descriptivos: `feat: agregar filtro de catálogo`, `fix: validar cantidad de pedido`, `docs: actualizar arquitectura`.
5. Abre un Pull Request hacia `main` y describe propósito, cambios y pruebas realizadas.
6. No incluyas `.env`, credenciales, datos personales ni dependencias instaladas (`node_modules`).
7. Actualiza la documentación cuando cambien requisitos, arquitectura, datos o instrucciones.

Las contribuciones deben respetar los módulos oficiales: Catálogo de Productos, Ventas y Administración.
